⚠ Not seeing posts in Business Suite Planner?
Most common reason: Your Meta App is in Development Mode and "Sample Page" is a test page — it's not the same as your real Business Manager page.

To fix this: go to Settings → Meta → Meta App Checker → run the check to diagnose your token and permissions. Then make sure you're posting to your actual Business Page (the one that appears in your Business Manager), not the sample/test page.

🔒 Upgrade to Permanent Tokens Never expires
Short-lived tokens expire in 1 hour. This converts your token into: (1) a 60-day user token, and (2) permanent per-Page tokens that never expire. Each Page token works forever — no refresh needed.
Before using this you need a Meta App with App Secret:
1. Go to developers.facebook.com/apps → Create App → Business → name it
2. Add products: Facebook Login for Business + Instagram
3. App settings → Basic → copy App ID and click "Show" to get App Secret
4. Paste short-lived token (from Graph API Explorer, with all permissions) below, along with App ID + App Secret
